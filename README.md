# 麦门读心术 McMindReader

> 不问你想吃麦当劳的什么——这个问题你自己都答不上来。它问的是"想吃苹果还是坚果""深夜脚步停在烤串摊还是雪花冰店"，然后反推出你此刻的馋点画像，配好最优优惠券，一次给你 2 套方案。不想选？手气套餐随机抽 1 套，还能限预算。

## 项目介绍

"中午吃什么"是当代人每天最累的决定，而更累的是：用户往往连自己想要什么都说不清。直接问"你想吃什么"得到的永远是"随便"。麦门读心术绕开了这个死结——**通过和麦当劳无关的具体食物选择题，让用户的直觉替他作答，再从答案反推馋点画像**（肉量、清爽、甜度、咸香、冰爽、扎实碳水、轻负担七个维度），用画像匹配麦当劳套餐，并自动配好最省钱的优惠券组合。

它还内置一套 **MBTI 式性格定位**：4 道性格二选一（E/I、S/N、T/F、J/P）加一道干饭强度题，先输出一份完整的"麦门人格分析报告"（4 字母类型 + 麦门原型 + 逐字母解读 + 性格→馋点换算），再按人格配餐——先懂你这个人，再懂你这一餐。

它解决三件事：**把"我说不清想吃啥"变成"3 道题就暴露了"；把"推荐永远撞同款"变成"2 套方案定位错开"；把"券规则看不懂"变成"券后价直接算好"。**

## 三种玩法

**① 🧭 馋点定位（6 题，每次不重样）**

> "桌上摆着两样，你先拿冰苹果还是盐焗坚果？" → 6 道实物画面题，每题从 6 个选项池随机抽 3 个——同一个用户来两次，题目大概率完全不同。答完得到馋点画像 → 🎯 最匹配 + 🔄 换换口味两套方案，匹配度前三名带分数公示。

**② 🧠 性格定位（MBTI 式，先分析后推荐）**

> "朋友说'随便你点'，你秒算性价比还是挑大家开心的？" → 5 题 3 选 1（4 个性格轴 + 干饭强度），先出一份人格分析报告（如 ENTP · 麦门分析家 · 🍖 猛干模式），再按人格配餐。性格题库可替换、可扩充，每次随机轮换。

**③ 🎰 手气套餐（不想选就直接抽）**

> 填个预期价格（或不填），随机抽 1 套，自动配最优券——预算内没有就放开限制并明确告知。

## 科学上的诚实

"馋什么=缺什么"整体科学证据有限。本 Skill 把信号分成两层：口味偏好是弱信号（低权重），而**睡眠不足→渴望高能量食物、大量出汗→电解质流失、经期/疲劳→铁、抽筋→镁钾、便秘→纤维**这些有研究支撑的生理信号是强信号（高权重）。推荐是启发式加权结果，输出中会明确标注，不冒充体检报告。

## 快速开始

**前置条件**：麦当劳中国大陆会员（手机号在 [open.mcd.cn/mcp](https://open.mcd.cn/mcp) 申请 MCP Token）+ 任意支持 MCP 的 AI 客户端（WorkBuddy / Cherry Studio / Cursor 等）

1. 配置 MCP（Token 替换后填入客户端）：

```json
{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn/mcp-servers/mcd-mcp",
      "headers": { "Authorization": "Bearer YOUR_MCP_TOKEN" }
    }
  }
}
```

> 💡 部分客户端（如 WorkBuddy 桌面版）直连可能因 Windows 证书吊销检查离线而失败，改用 `scripts/mcd-bridge.js` 本地桥接即可（Token 走环境变量），详见 [MCP_INTEGRATION.md](MCP_INTEGRATION.md)。

2. 把本仓库放入你的 AI 客户端工作目录，加载 [SKILL.md](SKILL.md)
3. 对它说第一句话："我想吃麦当劳，帮我测测"

**零 MCP 也能玩**：基础模式纯本地数据（`data/combo-pool.json` 31 套，热量来自官方 MCP 实拉），不配置 MCP 也能完整体验三种模式。

## 目标用户

- 说不出"想吃什么"、只会说"随便"的决策疲劳患者
- 相信"性格决定晚饭"的 MBTI 爱好者
- 想吃明白券、不想研究满减规则的省钱党
- 帮朋友/家人代点、需要快速收敛选项的"点单代表"

## 隐私与安全

- 题目作答数据不落盘、不上传，测完即走
- 领券、下单等写操作前必须逐项确认，绝不静默执行
- Token 从环境变量读取，绝不写入文件或对话
- 推荐为趣味启发式推断，不构成医疗或营养建议

## 技术栈

- 麦当劳官方 MCP Server（`https://mcp.mcd.cn/mcp-servers/mcd-mcp`），工具编排与工程发现详见 [MCP_INTEGRATION.md](MCP_INTEGRATION.md)
- 数据层：`data/combo-pool.json`（31 套 × 7 维馋点向量，热量为官方实拉值）+ `data/quiz-bank.json`（36 个实物选项池 + 45 个 MBTI 题库选项，可替换可扩充）
- 单页 Web 版：`assets/index.html`（零依赖，可直接打开体验完整三种模式）
- WorkBuddy（开发与运行环境）
